# 落地生根：通用外語 Units 課綱（檢閱版）

> 本檔由 [`落地生根.json`](./落地生根.json) 的 128 筆 Units 整理成表格，供人工閱讀、審查與討論。
> **資料來源以 JSON 為準**。修改課綱時應同步更新 JSON；本 Markdown 不作為另一份獨立的資料來源。
> 此為跨語言、跨地區的通用課綱；具體詞彙、當地風俗、制度與語言難度由教材總規範及後續生成流程決定。

## 說明

- 每一列代表一個 Unit；`context` 是大情境，`scenario` 是其中的子情境，`description` 是學完後希望完成的實際溝通任務。
- `U001`–`U128` 為穩定識別碼，不應僅為重新排序或更換階段而改動。
- 原始 JSON 中所有 Units 的 `level` 均為 `null`，表示不在這份通用模板預先指定難度；可由實際教材的 `default_level` 繼承。
- 原始 JSON 中所有 Units 的 `requirements` 均為空字串，表示尚無額外的 Unit 專用規範。
- 下方逐列保留原 JSON 的情境與能力描述，不再增添原本沒有的學習目標。
